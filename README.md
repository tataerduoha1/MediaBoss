# MediaBoss

本地视频 / JAV 媒体库一站式管理：**纯 Python 标准库实现，零第三方依赖，开箱即用**。

> 版本 1.4.1 · Python 3.11+ · Windows / Linux / macOS

---

## ✨ 功能总览

| 模块 | 功能 |
|------|------|
| 视频库 | 目录扫描、封面网格、多条件筛选（观看/收藏/评分/格式/目录/标签）、搜索、排序（含随机）、分页、批量按模板重命名整理 |
| JAV 库 | 海报墙、多维筛选（女优/厂商/系列/类别）、A–Z 番号首字母快速筛选条、搜索、排序（含随机）、详情页（元信息/演员/类别/标签/相关推荐） |
| 播放器 | 网页播放（HTTP Range 流媒体）、**智能转码**（按实际编码与容器而非扩展名判定：H.265/HEVC、WMV、AVI(MPEG-4)、FLV、H.264 10bit、AC3/DTS 及 TS 容器（含 .mp4 扩展名的假 MP4）等不兼容格式服务端 ffmpeg 实时转码为网页直播，兼容编码零开销直连；转码模式进度条为整片总长可拖动，直连失败可一键切换转码，转码流异常中断自动提供续播重试）、进度条悬停缩略图预览（雪碧图）、拖动预览松手跳转、快进快退、倍速（记忆）、全屏、画中画、断点续播、播放历史、看片截图、调用 mpv（仅服务器本机网页可用）、常驻退出按钮、完整快捷键（`?` 查看帮助）、移动端窄屏自动精简控制栏 |
| 刮削 | javbus / javdb 元数据 + 封面、中文翻译、失败自动重试（最多 3 次）+ 冷却期、按番号手动重刮 |
| 更新任务 | **增量更新**（只处理新增与失败项）/ **全量更新**（全部重刮），实时进度条（总计/成功/失败/跳过/已进行时长/预计剩余），随时取消 |
| 数据管理 | 数据字典（每类数据的类型/作用/位置/大小/清除方式/重建方式）、一键清缓存、压缩数据库（VACUUM）、重置刮削状态、工厂重置 |
| 下载 | 磁力链任务管理 |
| 系统 | 密码登录（会话 30 天）、API 令牌、ffmpeg 自动安装、响应式适配手机/平板、10 套主题（暗色/亮色/纯黑/暖棕/墨绿/羊皮纸/深海/霓虹/黑金/樱花）+ 跟随系统 + 自定义强调色/壁纸、局域网访问（IPv4+IPv6 双栈） |

## 🚀 快速开始

```bash
# 1. 需要 Python 3.11 及以上（仅标准库，无需 pip install 任何包）
python server.py
```

- 首次启动自动创建 `data/` 目录并初始化数据库。
- 浏览器自动打开 `http://127.0.0.1:8656`，默认密码 `admin`，请登录后立即在「设置 → 账户」修改。
- 局域网内手机/平板访问 `http://<电脑IP>:8656` 即可（首次启动 Windows 可能弹防火墙授权，允许「专用网络」）。

### 启动参数

| 参数 | 说明 |
|------|------|
| `-port 8656` | 监听端口 |
| `-host ""` | 监听地址；`""`/`0.0.0.0`/`::` = 所有接口（默认，允许局域网），`127.0.0.1` = 仅本机 |
| `--data-dir <目录>` | 指定数据目录（默认 `./data`） |
| `--no-browser` | 启动时不自动打开浏览器 |

也可通过项目根目录的 `config.toml` 固化配置：

```toml
[app]
port = 8656
host = ""            # "" = 全接口；127.0.0.1 = 仅本机
# data_dir = "D:/MediaBossData"
```

## 📂 目录结构

```
MediaBoss/
├── server.py            # 唯一入口
├── config.toml          # 启动配置（可选）
├── app/                 # 后端（Python 标准库）
│   ├── httpd.py         # 微型 HTTP 框架：路由/会话/Range 流媒体
│   ├── db.py            # SQLite（WAL）+ 版本迁移
│   ├── api/             # REST API
│   ├── services/        # 扫描器/刮削器/缩略图/下载
│   └── web/             # 前端（原生 ES Modules SPA）
├── data/                # 全部运行数据（可整体备份/迁移）
│   ├── mediaboss.db     # SQLite 数据库（长期）
│   ├── covers/          # 封面与头像（缓存，可重建）
│   ├── thumbs/          # 视频缩略图（缓存，可重建）
│   ├── sprites/         # 播放进度条预览图（缓存，可重建）
│   ├── screenshots/     # 用户截图（长期资产）
│   ├── cache/           # 临时文件（随时可清）
│   ├── logs/            # 运行日志（随时可清）
│   └── bin/             # ffmpeg / ffprobe（自动下载）
└── docs/                # 本文档集
    ├── 操作手册.md
    └── 维护与移植手册.md
```

## 🆚 与同类项目（JavBoss）对比

| 维度 | MediaBoss | JavBoss |
|------|-----------|---------|
| 运行依赖 | 纯 Python 标准库，零依赖，Python 3.11+ 即跑 | Go + React，需编译前端或下载构建产物 |
| 安装 | 单目录拷贝即用 | 需 Go 环境/二进制 + 前端构建 |
| 数据管理 | 内置数据字典可视化（类型/作用/位置/大小/清除/重建），一键清缓存、VACUUM、工厂重置 | 无专门数据管理面板 |
| 更新机制 | 全量/增量更新可选 + 实时进度（成功/失败/总计/时长/ETA）+ 取消 | 无统一更新任务与进度 |
| 刮削可靠性 | 失败重试 3 次 + 15 分钟冷却 + 终态标记，不会无限重试 | 重试策略较简单 |
| 服务器负担 | 扫描间隔 ≥5 分钟可配、翻译单队列、缩略图限并发 | 定时任务频率不可调 |
| 主题 | 10 套主题 + 跟随系统 + 自定义强调色/壁纸，防闪烁；播放器控件全场景高对比 | 暗色为主 |
| 多端 | 响应式 + IPv4/IPv6 双栈局域网访问 | 有局域网支持 |
| 播放器 | 拖动预览、雪碧图、画中画、断点续播、完整快捷键 + 帮助面板、**不兼容编码自动转码网页播放** | 功能相近，快捷键可配置 |
| 前端 | 原生 ES Modules，无构建步骤 | React 构建 |
| 短板 | HLS 外部播放源、批量播放、可配置快捷键暂未支持 | 支持 HLS 源与批量播放 |

> MediaBoss 的相对短板已在持续补齐（首字母筛选、随机排序均已实现）。
