# MediaBoss 操作手册

日常使用指南。安装与启动见 [README](../README.md)，数据管理与维护见 [维护与移植手册](维护与移植手册.md)。

## 1. 登录与账户

- 首次启动默认密码 `admin`，登录后请立即到 **设置 → 账户** 修改密码。
- 会话有效期 30 天，同一浏览器无需重复登录。
- 需要在脚本 / 第三方工具中调用 API 时，可在 **设置 → 账户** 创建 API 令牌，请求头携带 `Authorization: Bearer <token>` 或 Cookie。
- 忘记密码：停止服务，删除数据库中的 `password_hash` / `password_salt` 两个设置项（或直接用工厂重置，见维护手册），重启后恢复默认 `admin`。

| 💋 JAV 库 | 已刮削影片海报墙：女优/厂商/系列/类别筛选、**A–Z 首字母快速筛选条**、排序（含**随机**）、分页；点击进入详情页 |

| 📈 观影统计 | 年度报告（播放次数/时长/榜单）、观影热力日历、女优合作网络图，右上角切换年份 |

| 🕘 观看历史 | 播放记录（同一视频只保留一条、显示最近观看进度），点击续播；支持单条删除、勾选批量删除、一键清空 |
| ⚙️ 设置 | 媒体目录、刮削、外观、账户、**数据管理** |

顶栏通用功能：

- **🔍 搜索框**：全局搜索，按 `Enter` 跳转视频库搜索结果；任意页面按 `/` 快速聚焦。
- **🎲 幸运骰子**：一键随机播放一部影片（优先未看），选择困难症专用。
- **⌘ 快速跳转（Ctrl+K）**：任意页面按 `Ctrl+K` 打开命令面板，↑↓ 选择、`Enter` 打开；输入关键词同时搜索 JAV 库与视频库。
- **🔄 更新按钮 / 任务胶囊**：打开更新任务对话框（见下节），胶囊实时显示后台任务状态（扫描/刮削/缩略图队列）。
- 手机端：左上 `☰` 展开侧边栏。

## 3. 更新媒体库（扫描 + 刮削）

点击顶栏 **「🔄 更新」** 打开更新对话框：

1. **选择模式**
   - **增量更新**（推荐日常使用）：扫描目录找出新增/删除的文件，只对「未刮削」和「刮削失败」的影片重新请求网络，已成功的不会重复请求——速度快、负担小。
   - **全量更新**：重置全部影片的刮削状态并全部重刮。适用于更换刮削源、修正错误数据。已刮削成功的数据会被覆盖更新，不会产生冲突。
2. **同时重建缩略图**：勾选后对无封面视频重新生成缩略图（一般无需勾选，后台会自动补齐缺失的）。
3. 点击 **开始更新**，实时显示：
   - 进度条（已完成 / 总计）
   - **总计 / 成功 / 失败 / 跳过** 计数
   - **已进行时长** 与 **预计剩余时间**
   - 当前正在处理哪个番号；失败明细列表可展开查看原因
4. 随时点击 **取消** 停止任务（队列立即清空，已完成的保留）。

**刮削失败怎么办？** 失败影片自动进入冷却期（默认 15 分钟，可在设置中调整），冷却结束自动重试，最多 3 次后标记为「失败」不再打扰。可在 JAV 库筛选「只看失败」查看，或到详情页手动「🔄 重新刮削」。确认番号无法在刮削源找到的（如自制内容），会被标记为「无番号」跳过。

**刮削源说明**：内置 6 源——JavBus（主）、JavDB、JavLib、DMM/FANZA、FC2（仅 FC2-PPV 番号）、MissAV。按设置→刮削中的「数据源顺序」依次尝试（如 `javbus,javdb,dmm,missav`，默认只用前两个，**加入顺序即启用**）；**某源失败/未找到会自动换下一个源**，命中时会写日志「刮削命中 via 源名」。域名管理：设置→刮削→「**源域名列表**」一个框管所有源，格式 `javbus=镜像域名,dmm=镜像域名`（源名 javbus/javdb/javlib/dmm/fc2/missav，留空用默认；顺序里写了无效源名会在日志告警）。注意：均为非官方 HTML 抓取，当前网络下多数源直连会被反爬拦截（403/JS 渲染），**建议配合网络代理使用**；站点改版导致解析失效需升级版本。

## 4. 视频播放

点击卡片进入详情页 → **▶ 网页播放**。

播放器功能：

- **进度条**：悬停显示缩略图预览（雪碧图）；**拖动时只预览不跳转，松手才跳转**——避免误触。触屏同样支持。
- **双击画面**：左 1/3 快退 10 秒、右 1/3 快进 10 秒、中间切换全屏。
- **倍速**：0.5x–3x，自动记忆上次选择。
- **常驻退出**：左上角「← 退出」按钮始终可点——控制栏自动隐藏时它保持半透明常驻、悬停即高亮，`Esc` / `Backspace` 亦可随时退出播放。
- **断点续播**：中途退出后再次进入询问或自动跳转到上次位置；播完自动标记「已看完」。
- **截图**：播放中可截图，保存到 `data/screenshots/`，详情页可查看。
- **外挂字幕**：视频同目录下存在同名 `.srt` / `.ass` / `.ssa` / `.vtt` 字幕时自动加载（编码自动识别），出现 CC 按钮，按 `C` 或点击开关字幕。
- **🖥 mpv 播放**：详情页按钮，调用**服务器电脑**上的 mpv 打开原文件（需在设置中配置 mpv 路径）。仅限在服务器本机打开的网页显示/使用——手机等局域网设备看不到该按钮（远端触发会在服务器屏幕上弹窗口，后端也直接拒绝）。
- **⚡ 智能转码（网页直播不兼容格式）**：进入播放页时自动检测视频/音频编码（**按实际编码与容器判定，与文件扩展名无关**——.mp4 里装了 H.265 照样转码，.avi 里的 H.264 照样直连；例外：**TS 容器**（.ts 文件，及扩展名为 .mp4 但容器实为 TS 的"假 MP4"，下载站常见）浏览器无法解封装，一律强制重编码）——
  - 浏览器原生支持（H.264 8bit / VP8 / VP9 / AV1 + AAC / MP3 / Opus / FLAC 等）→ 原文件直接流播放，零开销，**不画蛇添足转码**；
  - 编码不兼容（**H.265/HEVC、WMV、AVI(MPEG-4)、FLV、H.264 10bit** 等）或音频不兼容（**AC3 / DTS / WMA** 等）→ 服务端 ffmpeg **实时转码**为 fMP4 网页直播，无需任何外部播放器；控制栏出现「⚡ 转码」徽标；
  - 转码智能分流：视频编码兼容时视频流**直接拷贝不重编码**（近零 CPU），只转不兼容的部分（如仅音频），流畅省电；
  - 转码播放的进度条始终为**整片总长**，可任意位置拖动；拖动 / 快进快退会短暂重启转码（显示「转码跳转中…」，数秒内恢复），属正常现象；
  - 直连播放若意外失败（个别编码变体浏览器不支持），错误提示中出现「⚡ 尝试转码播放」按钮，可一键切换为转码观看；
  - 转码流若意外中断（网络抖动 / 服务重启），未播到整片 90% 不会误报"播放结束"，而是出现「↻ 重试转码」提示，点击即可从当前位置续播；
  - 依赖 ffmpeg（设置页可一键自动安装）；ffmpeg 不可用时自动回退为原行为并提示。
- **编码兼容性**：浏览器普遍不支持 H.265/HEVC 解码——已配置 ffmpeg 时此类视频会自动转码网页播放（见上）；未配置 ffmpeg 时播放器会显示明确提示与编码信息，并提供「🖥 用 mpv 播放」一键按钮作为替代；H.264 视频网页播放不受影响。
- **画中画**：`P` 键或按钮，边播放边做其他事。

### ⌨ 快捷键（播放页按 `?` 随时查看）

| 按键 | 功能 |
|------|------|

## 5. 标记与整理

- **收藏 / 评分 / 已看**：卡片悬停按钮或详情页操作。
- **标签**：详情页「＋ 编辑标签」，逗号分隔多个。
- **🖼 自选海报**：详情页封面旁按钮，按视频时长 8 等分抽帧，点选一帧即设为封面（替换刮削封面，网页缩略图与 NFO 导出同步生效），也可一键恢复默认。
- **批量整理**（视频库 → 🗂 整理）：按模板 `{code} {title}` 重命名已刮削的文件（原地改名，不移动目录），先预览确认再执行。
- **导出 NFO**：详情页按钮，生成 Kodi / Emby 兼容的 NFO 元数据文件。

### 5.1 观看历史管理

- **一条记录**：同一视频只保留一条观看记录（最新一次），重复播放不会堆积。
- **进度显示**：每条记录显示最近观看位置（"看到 12:34"），点击行直接续播。
- **删除**：单条 → 行尾 `✕`；多条 → 勾选后点「删除所选（n）」；全部 → 「🗑 清空全部」。
- 删除记录不影响视频文件与播放进度（续播位置仍保留）。

### 5.2 无封面影片的显示

刮削失败或源站搜不到的番号，会显示**番号渐变占位卡**（按番号生成稳定配色的海报式占位），
而不是破损图片；ffmpeg 可用时未刮削视频自动回退显示缩略图。

### 5.3 片单（收藏合集）

- **新建**：片单页「＋ 新建片单」；也可在 JAV 详情页「📋 加入片单」弹窗中直接输入名称回车创建并加入。
- **管理**：详情页勾选 / 取消勾选即加入 / 移除；片单详情页支持重命名、删除、条目封面设置与移除。
- 片单卡片封面自动取第一个成员影片的封面。

### 5.4 观影统计

- **年度报告**：总播放 / 总时长 / 看过影片 / 活跃天数 / 日均播放 / 最疯狂一天，附每月柱状图与四大榜单（最受欢迎影片、最常看女优、最爱类别、常看厂商）。
- **观影热力日历**：GitHub 风格的全年打卡图，颜色越深当日播放越多，悬停查看日期明细。
- **女优合作网络**：以连线展示「同一部影片共同出演 ≥2 次」的女优组合，节点大小代表影片数、连线粗细代表合作次数。
- 右上角下拉切换统计年份。

### 5.5 工具箱

- **🔁 重复文件检测**：自动找出「同番号多文件」与「同大小且时长接近」的疑似重复，每组标注建议保留（体积最大）与疑似多余，点击跳转播放页核对后手动处理。**同一视频复制到多个目录会各自独立入库**（1.4.1 起），重复检测可正确发现；检测前先确保两份文件都已扫描入库。
- **📦 存储分析**：影片总占用、各监控目录 / 各格式占比、缓存目录（封面 / 缩略图 / 雪碧图等）明细、最大的 20 个文件排行；「🧹 清理孤儿缓存」一键删除数据库中已无对应视频的封面与缩略图。
- **🗃 NFO 批量导出**：把全部已刮削影片打包导出为 `{番号}.nfo + {番号}.jpg` 的 zip（单包 500 部自动分包），供 Kodi / Emby 等媒体中心导入；可按关键词筛选、选择是否包含封面。

## 7. 手机 / 平板使用

- 与电脑同一局域网，浏览器访问 `http://<电脑IP>:8656`。
- 界面自动响应式：侧边栏折叠、播放器隐藏音量条、触摸区域加大。
- **竖屏窄屏下播放控制栏自动精简**：隐藏音量/静音（用手机硬件音量键）、画中画、快捷键帮助（触屏无键盘），并收紧时间与徽标间距——保证播放/快进快退/倍速/全屏一行完整可见，不再被裁切；极窄屏放不下时自动换行兜底。
- **安装为应用（PWA）**：手机浏览器菜单选「添加到主屏幕」后，可像原生应用一样全屏打开、拥有独立图标；桌面 Chrome / Edge 地址栏右侧同样可安装。
- iOS Safari 播放受系统限制（自动播放需手动点一次；画中画/全屏行为与桌面略有差异）。
- 服务器监听所有网卡（IPv4 + IPv6）；如需禁止局域网访问，在 `config.toml` 设 `host = "127.0.0.1"`。

## 8. 常见操作技巧

- 想换一批封面效果？→ 全量更新会重新下载封面。
- 磁盘快满了？→ 工具箱「📦 存储分析」查看大头，再跑一遍「🧹 清理孤儿缓存」。
- 收藏的影片太多找不到？→ 片单归类 + `Ctrl+K` 快速跳转。
- **备份 / 迁移**：设置 → 📦 下载数据备份（含数据库 + 封面 + 自定义海报的 zip）；换机或重装时用「♻️ 恢复备份」上传即可完整还原（恢复会覆盖现有数据，操作需二次确认）。
- **检查更新**：设置 → 关于 → 「🔍 检查更新」，有新版本时显示更新说明与下载链接；仓库未发布 Release 时会给出提示。
- 数据库文件越来越大？→ 设置 → 数据管理 → **压缩数据库**（VACUUM）。
- 某影片信息刮错了？→ 详情页「✏️ 编辑」手动修正，或删除后重新刮削。
- **列表位置记忆**：从列表进入详情/播放后返回，列表自动回到之前的页码与滚动位置，不用重新翻页下滑（会话内有效）。
- 界面出现异常？→ `Ctrl+Shift+R` 强制刷新（JS/CSS 更新后无需手动清缓存，服务器已配置自动再验证）。
