# MediaBoss 操作手册

日常使用指南。安装与启动见 [README](../README.md)，数据管理与维护见 [维护与移植手册](维护与移植手册.md)。

---

## 1. 登录与账户

- 首次启动默认密码 `admin`，登录后请立即到 **设置 → 账户** 修改密码。
- 会话有效期 30 天，同一浏览器无需重复登录。
- 需要在脚本 / 第三方工具中调用 API 时，可在 **设置 → 账户** 创建 API 令牌，请求头携带 `Authorization: Bearer <token>` 或 Cookie。
- 忘记密码：停止服务，删除数据库中的 `password_hash` / `password_salt` 两个设置项（或直接用工厂重置，见维护手册），重启后恢复默认 `admin`。

## 2. 页面导览

| 页面 | 功能 |
|------|------|
| 📊 仪表盘 | 媒体库统计（总数/时长/大小/女优数）、最近添加、继续观看 |
| 🎬 视频库 | 全部视频文件网格：搜索、观看状态/收藏/评分/格式/目录筛选、排序（添加时间/文件时间/大小/时长/评分/播放次数/最后播放/标题/**随机**）、分页、批量整理 |
| 💋 JAV 库 | 已刮削影片海报墙：女优/厂商/系列/类别筛选、**A–Z 首字母快速筛选条**、排序（含**随机**）、分页；点击进入详情页 |
| 👩 演员 / 🏢 厂商 / 📚 系列 / 🏷 类别 | 实体浏览，点击实体跳转对应筛选结果 |
| 🕘 观看历史 | 播放记录（同一视频只保留一条、显示最近观看进度），点击续播；支持单条删除、勾选批量删除、一键清空 |
| ⬇️ 下载 | 磁力链任务管理与进度 |
| ⚙️ 设置 | 媒体目录、刮削、外观、账户、**数据管理** |

顶栏通用功能：

- **🔍 搜索框**：全局搜索，按 `Enter` 跳转视频库搜索结果；任意页面按 `/` 快速聚焦。
- **🔄 更新按钮 / 任务胶囊**：打开更新任务对话框（见下节），胶囊实时显示后台任务状态（扫描/刮削/缩略图队列）。
- 手机端：左上 `☰` 展开侧边栏。

## 3. 更新媒体库（扫描 + 刮削）

点击顶栏 **「🔄 更新」** 打开更新对话框：

1. **选择模式**
   - **增量更新**（推荐日常使用）：扫描目录找出新增/删除的文件，只对「未刮削」和「刮削失败」的影片重新请求网络，已成功的不会重复请求——速度快、负担小。
   - **全量更新**：重置全部影片的刮削状态并全部重刮。适用于更换刮削源、修正错误数据。已刮削成功的数据会被覆盖更新，不会产生冲突。
2. **同时重建缩略图**：勾选后对无封面视频重新生成缩略图（一般无需勾选，后台会自动补齐缺失的）。
3. 点击 **开始更新**，实时显示：
   - 进度条（已完成 / 总计）
   - **总计 / 成功 / 失败 / 跳过** 计数
   - **已进行时长** 与 **预计剩余时间**
   - 当前正在处理哪个番号；失败明细列表可展开查看原因
4. 随时点击 **取消** 停止任务（队列立即清空，已完成的保留）。

**刮削失败怎么办？** 失败影片自动进入冷却期（默认 15 分钟，可在设置中调整），冷却结束自动重试，最多 3 次后标记为「失败」不再打扰。可在 JAV 库筛选「只看失败」查看，或到详情页手动「🔄 重新刮削」。确认番号无法在刮削源找到的（如自制内容），会被标记为「无番号」跳过。

## 4. 视频播放

点击卡片进入详情页 → **▶ 网页播放**。

播放器功能：

- **进度条**：悬停显示缩略图预览（雪碧图）；**拖动时只预览不跳转，松手才跳转**——避免误触。触屏同样支持。
- **双击画面**：左 1/3 快退 10 秒、右 1/3 快进 10 秒、中间切换全屏。
- **倍速**：0.5x–4x，自动记忆上次选择。
- **断点续播**：中途退出后再次进入询问或自动跳转到上次位置；播完自动标记「已看完」。
- **截图**：播放中可截图，保存到 `data/screenshots/`，详情页可查看。
- **🖥 mpv 播放**：详情页按钮，调用本机 mpv 打开原文件（需在设置中配置 mpv 路径）。
- **编码兼容性**：浏览器普遍不支持 H.265/HEVC 解码，此类视频网页播放会失败——播放器会显示明确提示与编码信息，并提供「🖥 用 mpv 播放」一键按钮作为替代；H.264 视频网页播放不受影响。
- **画中画**：`P` 键或按钮，边播放边做其他事。

### ⌨ 快捷键（播放页按 `?` 随时查看）

| 按键 | 功能 |
|------|------|
| 空格 | 暂停 / 播放 |
| ← / → 或 J / L | 后退 / 前进 10 秒 |
| ↑ / ↓ | 音量加减 |
| 0–9 | 跳转到 0%–90% 位置 |
| F | 全屏切换 |
| M | 静音 |
| P | 画中画 |
| Esc | 退出全屏 / 返回上一页 |

## 5. 标记与整理

- **收藏 / 评分 / 已看**：卡片悬停按钮或详情页操作。
- **标签**：详情页「＋ 编辑标签」，逗号分隔多个。
- **批量整理**（视频库 → 🗂 整理）：按模板 `{code} {title}` 重命名已刮削的文件（原地改名，不移动目录），先预览确认再执行。
- **导出 NFO**：详情页按钮，生成 Kodi / Emby 兼容的 NFO 元数据文件。

### 5.1 观看历史管理

- **一条记录**：同一视频只保留一条观看记录（最新一次），重复播放不会堆积。
- **进度显示**：每条记录显示最近观看位置（"看到 12:34"），点击行直接续播。
- **删除**：单条 → 行尾 `✕`；多条 → 勾选后点「删除所选（n）」；全部 → 「🗑 清空全部」。
- 删除记录不影响视频文件与播放进度（续播位置仍保留）。

### 5.2 无封面影片的显示

刮削失败或源站搜不到的番号，会显示**番号渐变占位卡**（按番号生成稳定配色的海报式占位），
而不是破损图片；ffmpeg 可用时未刮削视频自动回退显示缩略图。

## 6. 设置项速查

| 设置 | 说明 | 默认 |
|------|------|------|
| 扫描间隔 | 自动扫描媒体目录的周期，**最低 5 分钟**，避免频繁扫描占磁盘 | 5 分钟 |
| 刮削重试冷却 | 失败后的重试等待时间 | 15 分钟 |
| 翻译 | 网络刮削的标题翻译为中文 | 开 |
| 刮削源顺序 | javbus → javdb | - |
| 代理 | 刮削请求使用的 HTTP 代理（如需） | 空 |
| 缩略图并发 | ffmpeg 截图线程数，低配机器建议 1-2 | 2 |
| 雪碧图 | 播放进度条预览图生成 | 开 |
| 主题 | 暗色 / 亮色 / 跟随系统 | 暗色 |
| 每页数量 | 列表分页大小（10–200） | 60 |
| 整理模板 | 批量重命名模板 | `{code} {title}` |

## 7. 手机 / 平板使用

- 与电脑同一局域网，浏览器访问 `http://<电脑IP>:8656`。
- 界面自动响应式：侧边栏折叠、播放器隐藏音量条、触摸区域加大。
- iOS Safari 播放受系统限制（自动播放需手动点一次；画中画/全屏行为与桌面略有差异）。
- 服务器监听所有网卡（IPv4 + IPv6）；如需禁止局域网访问，在 `config.toml` 设 `host = "127.0.0.1"`。

## 8. 常见操作技巧

- 想换一批封面效果？→ 全量更新会重新下载封面。
- 数据库文件越来越大？→ 设置 → 数据管理 → **压缩数据库**（VACUUM）。
- 某影片信息刮错了？→ 详情页「✏️ 编辑」手动修正，或删除后重新刮削。
- **列表位置记忆**：从列表进入详情/播放后返回，列表自动回到之前的页码与滚动位置，不用重新翻页下滑（会话内有效）。
- 界面出现异常？→ `Ctrl+Shift+R` 强制刷新（JS/CSS 更新后无需手动清缓存，服务器已配置自动再验证）。
